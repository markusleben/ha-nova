## Bug Fixes

- The write flow's consumer scan now fails closed: a failed or wrong-path `search/related` read renders as "consumer check inconclusive" instead of silently claiming that nothing else is affected. (#489)
- Skills no longer probe unfamiliar HTTP write endpoints with empty bodies — on `/core` POST paths this could silently create objects (observed: an empty Alarmo area). Custom-integration configuration APIs (Alarmo, Scheduler, ...) are now an explicit, guarded fallback category. (#493)
