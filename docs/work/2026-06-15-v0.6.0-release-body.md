## New Features

- HA NOVA can now undo the last automation change it made: reply `revert` to roll it back, while new automations and deletes fall back to Home Assistant Backups.

## Bug Fixes

- The installer no longer aborts after a successful install when antivirus or a file indexer scans the new binary during cleanup, so installs now complete and land on PATH across Windows, macOS, and Linux.
- Re-installing on Windows after an interrupted uninstall no longer fails with a PowerShell error.
- Hardened the macOS keychain step so your Home Assistant token is no longer briefly visible to other processes while it is stored during setup.
- Bumped a bundled dependency (`form-data`) to close a published high-severity advisory in both the main app and the Relay package.

## Install

**macOS / Linux**
```sh
curl -fsSL https://raw.githubusercontent.com/markusleben/ha-nova/v0.6.0/install.sh | HA_NOVA_VERSION=v0.6.0 bash
```

**Windows (PowerShell)**
```powershell
$env:HA_NOVA_VERSION = 'v0.6.0'
irm https://raw.githubusercontent.com/markusleben/ha-nova/v0.6.0/install.ps1 | iex
```

## Already Installed?

Run `ha-nova check-update` or `ha-nova update`.
