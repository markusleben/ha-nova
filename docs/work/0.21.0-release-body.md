## New Features

- **The install census — opt-in, anonymous, public numbers.** HA NOVA still has no telemetry. New: if you explicitly say yes (one interactive question in the terminal, or at most three AI-client callouts — then the question closes itself), it sends one anonymous ping per week: your HA NOVA version, relay version, and OS. There is no ID — we could not recognize you twice even if we wanted to — and the aggregate numbers are public for everyone. Change anytime: `ha-nova census on|off`. Details: `docs/reference/census.md` and `PRIVACY.md`. (#416)
