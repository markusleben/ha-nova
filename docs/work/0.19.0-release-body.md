## New Features

- **Passwordless onboarding.** On HA OS and Supervised, the NOVA Relay App now connects through Home Assistant's own Supervisor access — there is no Long-Lived Access Token to create, copy, or paste anymore. (#374)
- **Pair each device with one code.** Home Base grew into the **NOVA** page: click "Connect a device", type the one-time six-digit code on your computer, done. Every device gets its own credential over an encrypted, pinned connection (OPAQUE + SPKI-pinned TLS 1.3). (#374)
- **See and revoke your devices.** The NOVA sidebar page lists every paired computer — revoke any one of them with a click, without touching the others. (#374)
- **Works headless.** Servers, containers, LXCs, SSH sessions: when no desktop keyring is available, the device credential falls back to a private file automatically. (#382)
- **NOVA appears in your sidebar automatically.** The App enables its own sidebar entry on first start — once; hiding it later is always respected. (#384)

## Bug Fixes

- Fresh App installs could fail to start because a required option had no default — fixed. (#376)

## What To Watch

- **Upgrading from an earlier install?** Your existing shared relay token is migrated automatically on first start, and the stored plaintext is cleared. Legacy access keeps working until you revoke it — nothing breaks mid-upgrade.
- **To finish the move to per-device pairing:** run `ha-nova pair` on each computer once (one code each), then revoke the legacy shared access from the NOVA page.
- **App mode no longer needs `HA_LLAT`.** That variable now only applies to the standalone Container/Core relay.
- **Update the NOVA Relay App to 0.7.0** for pairing and the NOVA page — and take a backup before updating, as always.
