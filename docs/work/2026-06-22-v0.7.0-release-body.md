# v0.7.0 Release Body

Status: draft

## New Features

- Home Assistant status checks for read-only health checks across repairs, integrations, System Health, entity availability, and low-battery signals.
- Calendar skill for read-only calendar listing and bounded event windows.
- Install status JSON for clearer local support/debugging.
- `ha-nova trace latest` for safer automation/script trace debugging without manually guessing trace run IDs.
- Google Antigravity support replaces the old Gemini-facing client surface; the legacy `ha-nova setup gemini` alias still resolves to Antigravity.

## Bug Fixes

- Review now catches boolean-like templates compared to string `"True"` / `"False"` values.
- Review now warns about same-block `variables:` dependencies regardless of key order.
- Review now flags capacity-like variables that may accidentally use current `available_energy` instead of maximum/nominal capacity.
- Snapshot save now explains missing input instead of surfacing an empty JSON parse error.
- Automation updates now preserve existing notification wording unless the user explicitly asks to change it.
- Update previews now keep notification title/message changes visible even when the action list also changes.
- Write previews now use a clearer terminal-friendly structure with explicit `apply`, `show yaml`, and `cancel` choices.
- Deletes now treat verified absence as success and avoid unsafe alternate delete retries.

## What To Watch

- Skills now require NOVA Relay `0.2.3` or newer.
- Relay remains transport-only; the new System Health support uses generic bounded WS event collection.
- Google Antigravity detection is intentionally narrow: standard Windows per-user Desktop install or `agy`, and Linux `agy` / `antigravity` / `antigravity-ide` on `PATH`.
