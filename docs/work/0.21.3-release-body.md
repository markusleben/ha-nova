# 0.21.3 Release Body

> Bullet order expresses importance. Only the first action item plus the first
> two feature/fix items feed the compact update notice.

## What To Watch

- **Existing Census Yes choices will be asked again.** The old choice covered an identifier-free report; counting installations needs a new random Census ID. Reporting stays off until Yes; existing No remains No.

## New Features

- **Distinct opt-in installation counts.** Repeat reports use the dedicated random Census ID to count once. Private maintainer stats show active/known HA NOVA versions, OS, and recently observed Relay versions. (#437)
- **Official Relay totals stay separate.** Home Assistant Analytics Relay App counts are shown as a second metric and are never added to voluntary HA NOVA client counts. (#437)
- **Home Status explains unavailable entities.** Results now separate expected or transient states from actionable warnings using registry and update context. (#433)

## Bug Fixes

- **Cloudflare's role stays explicit.** It hosts Census HTTPS and receives source-IP/connection metadata. HA NOVA ingest does not read or store the IP; the dashboard remains private. (#437)
- **Unicode-safe Relay files.** Strict UTF-8 handling now preserves non-ASCII Home Assistant configuration on every platform, including Windows PowerShell 5.1. (#434)
- **Census reports use a rolling interval.** Yes sends the first report immediately; another report is sent no sooner than seven days later. (#437)
