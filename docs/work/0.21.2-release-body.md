# 0.21.2 Release Body

> Bullet order expresses importance. Only the first action item plus the first
> two feature/fix items feed the compact update notice.

## What To Watch

- **HA NOVA may ask for census consent again.** This happens only when an older installation never recorded an explicit Yes or No. Existing explicit choices remain unchanged.

## Bug Fixes

- **Census consent is now an explicit, inspectable choice.** Before the first report, HA NOVA offers separate **Yes**, **No**, and **Show exact data** actions. A Yes sends one report immediately and then allows at most one report per week.
- **The privacy wording now describes the complete network path.** The identifier-free JSON report passes through Cloudflare, the hosting provider. Cloudflare necessarily receives the source IP as connection metadata; HA NOVA does not include it in the JSON payload or read or store it. (#431)
- **Older informational notices no longer count as consent prompts.** Installations that auto-closed the previous machine notice are asked again, while recorded explicit Yes and No choices remain authoritative. (#431)
