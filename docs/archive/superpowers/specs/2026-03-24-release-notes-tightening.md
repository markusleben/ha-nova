# 2026-03-24: Release Notes Tightening

## Scope

- Tighten final and RC release notes before tagging.

## Decisions

- Keep release notes user-facing and short.
- Exclude `docs`, `refactor`, `perf`, `style`, `build`, `ci`, `chore`, and `test` commits from the autogenerated final changelog.
- Keep the final release body focused on:
  - why the release matters
  - what users get
  - upgrade notes
- Keep RC notes aligned to the same Windows lifecycle truth as the final release notes.

## Required Truth

- Public Windows path stays `install.ps1` until the `winget` package is published and proven.
- Default uninstall is standard remove; `--purge` is the full local wipe.
- Canonical Windows paths are `%APPDATA%\ha-nova` and `%LOCALAPPDATA%\ha-nova\cache`.
- One Windows install channel per machine.
