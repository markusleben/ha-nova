# 0.21.2 Release Body

## What To Watch

- **HA NOVA may ask for census consent again.** This happens only when an older installation never recorded an explicit Yes or No. Existing explicit choices remain unchanged.

## Bug Fixes

- **Census consent is now a clear choice.** Before the first report, choose **Yes**, **No**, or **Show exact data**. Yes sends one report now and permits at most one per week.
- **Cloudflare's role is now stated plainly.** Cloudflare, the hosting provider, receives the source IP for HTTPS delivery. The JSON contains no IP; HA NOVA does not read or store it. (#431)
- **Older informational notices no longer count as consent prompts.** Installations that auto-closed the previous machine notice are asked again, while recorded explicit Yes and No choices remain authoritative. (#431)
