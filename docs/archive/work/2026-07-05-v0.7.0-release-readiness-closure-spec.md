# v0.7.0 Release-Readiness Closure Spec

Date: 2026-07-05
Status: active

## Goal

Close the remaining v0.7.0 release blockers before PR review: Antigravity install proof, release-facing wording, write/helper output safety, and Home Assistant health-result correctness.

## Scope

Included:

- Release text uses `Home Assistant status checks` for public wording.
- Antigravity docs describe the current Google Antigravity client and real skill names.
- Antigravity install/status detection covers macOS app markers, Windows Desktop-only installs, and Linux launcher markers.
- Local Antigravity skill installs remove retired current-root skill names.
- Write/helper previews stay compact by default and offer YAML only on explicit request.
- Delete previews keep typed-token safety and hide internal helper entry IDs unless needed for disambiguation.
- `system_health/info` checks treat event-level `success:false` and `error` as failures.

Excluded:

- Client-registry redesign.
- Dependabot, workflow, or release-pipeline changes unrelated to this release blocker set.
- Notification-copy rewrites beyond necessary safety-contract alignment.
