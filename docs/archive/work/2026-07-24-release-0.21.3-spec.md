# HA NOVA 0.21.3 Hotfix Release Spec

Status: merged — released as v0.21.3
Date: 2026-07-24

## Purpose

Ship the reviewed Census installation-counting contract, contextual Home
Status reporting, and lossless Unicode Relay file handling.

## Scope

- Bump the HA NOVA skill/client version from 0.21.2 to 0.21.3.
- Keep the minimum Relay version at 0.7.1.
- Publish concise notes for distinct opted-in Census installations, the
  private maintainer dashboard, contextual unavailable/unknown states, and
  Unicode-safe Relay file operations.
- Keep official Relay App installation totals separate from voluntary HA NOVA
  client Census totals.
- Do not make the Census dashboard public.

## Release Gate

- Release-prep PR with the full SHA-specific review and merge checklist.
- RC required because the release changes Go code, Census Worker behavior, and
  deployment verification.
- Strict release-pipeline audit and dispatched disposable-HA E2E on the exact
  reviewed release-prep merge commit.
- Green RC publish plus public macOS/Linux and Windows installer verification.
- Cloudflare Access protection and a verified Census Worker deployment before
  the final tag.
- Green final publish plus public stable installer verification.

## Acceptance

- All version-bearing client/plugin manifests report 0.21.3.
- `version.json` and `nova/version.json` still require Relay 0.7.1.
- Release notes explain that old Yes choices are asked again because the
  payload now uses a dedicated installation ID; old explicit No remains final.
- Release notes describe subsequent reports as no sooner than seven days later.
- Census statistics stay private and count distinct participating
  installations without presenting them as people or the complete installed
  base.
- No open PR is an immediate release blocker.
