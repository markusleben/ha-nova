# 0.23.0 Release Body

Status: active

## New Features

- **Revoking a device now asks first.** The NOVA page confirms every destructive action on a dedicated screen that shows exactly which computer you are about to disconnect — name, when it was added, when it was last used, and whether it connects through Home Assistant Cloud. Resetting the device registry additionally requires typing RESET. (#482)
- **Recognizable device list.** Every device row shows when it was added and last used, and Cloud-connected devices carry a cloud badge — so two same-named entries are no longer a guessing game. (#482)

## Bug Fixes

- The write flow's consumer scan now fails closed: a failed or wrong-path `search/related` read renders as "consumer check inconclusive" instead of silently claiming that nothing else is affected. (#489)
- Skills no longer probe unfamiliar HTTP write endpoints with empty bodies — on `/core` POST paths this could silently create objects (observed: an empty Alarmo area). Custom-integration configuration APIs (Alarmo, Scheduler, ...) are now an explicit, guarded fallback category. (#493)
- Write previews keep their full Card form: the latency allowlist now includes the files that define the output contract, so previews no longer silently degrade to prose or hand-written diffs. (#494)
