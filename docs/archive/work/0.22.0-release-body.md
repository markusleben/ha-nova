# 0.22.0 Release Body

## New Features

- **Optional remote access through Home Assistant Cloud.** The setup wizard can
  now keep HA NOVA local, add Home Assistant Cloud as a secure fallback, or use
  Cloud only. The local-only path remains the recommended default. Cloud setup
  uses the user's paid Nabu Casa Remote UI, Home Assistant OAuth, native OS
  secure storage, and a separately revocable NOVA device pairing; HA NOVA does
  not operate another tunnel or hosted broker.

## Bug Fixes

- **Cleaner setup and diagnostics.** Official Home Assistant discovery avoids
  unrelated network devices, completed local installs offer Cloud fallback,
  and routine macOS diagnostics no longer open Keychain password prompts.

## What To Watch

- This release requires NOVA Relay 0.8.0. Update the App, or update the
  standalone container image, before using the new client.
- Cloud Remote launches as a desktop Beta for Home Assistant OS/Supervised on
  validated macOS, Windows, and Linux desktop environments. It requires an
  active Home Assistant Cloud subscription with Remote UI enabled. Headless,
  SSH, WSL, service, gateway, Container, and Core setups remain local-only.
