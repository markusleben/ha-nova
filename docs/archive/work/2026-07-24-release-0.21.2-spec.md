# HA NOVA 0.21.2 Hotfix Release Spec

Status: merged — released as v0.21.2
Date: 2026-07-24

## Purpose

Ship the census-consent and privacy-clarity fix reviewed and merged in #431.
Consent must be an explicit user action, the exact report must be inspectable
before a first send, and the network disclosure must explain Cloudflare's role
and unavoidable receipt of the source IP as transport metadata.

## Scope

- Bump the HA NOVA skill/client version from 0.21.1 to 0.21.2.
- Keep the minimum Relay version at 0.7.1; no Relay App source changed.
- Publish concise notes for the explicit Yes/No/data-preview interaction,
  corrected legacy prompt state, and complete Cloudflare disclosure.
- Deploy the reviewed census Worker after the release candidate passes.
- Do not change installers, Relay App version, or release machinery.

## Release Gate

- Release-prep PR with the full SHA-specific review and merge checklist.
- RC required because #431 changes shipped Go code and census Worker behavior.
- Strict release-pipeline audit and dispatched disposable-HA E2E on the exact
  reviewed release-prep merge commit.
- Green RC publish plus public installer verification before Worker deployment
  and the final tag.
- Green final publish plus public stable installer verification.

## Acceptance

- All version-bearing client/plugin manifests report 0.21.2.
- `version.json` and `nova/version.json` still require Relay 0.7.1.
- Release notes state that Cloudflare is the provider and receives the source
  IP as transport metadata without implying that the IP is in the JSON report.
- Release notes say "at most once per week" rather than using ISO-week
  terminology or inaccurately promising a rolling seven-day interval.
- No open PR is an immediate release blocker.
