# Support

Run `ha-nova doctor` first.

Then use the right channel:

- Bugs and feature requests:
  - open a GitHub issue
  - include exact steps, environment details, and relevant command output
- Security issues:
  - follow `SECURITY.md`
  - do not post publicly

## Conduct Reports

To report a Code of Conduct incident, contact the maintainer privately via GitHub:
- profile: `https://github.com/markusleben`
- handle: `@markusleben`
Do not post conduct reports in public issues or pull requests.
